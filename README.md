# 🔴 Metadex - Fast & Competitive Pokédex

> A lightning-fast, modern Pokédex built for teambuilding and competitive players. 
> **100% AI-Generated Project** 🤖

🌐 **Live Demo:** [metadex.vercel.app](https://metadex.vercel.app)

---

## 📖 The Story Behind Metadex
I'm a 16-year-old student from Italy with **zero coding experience**. I love competitive Pokémon and wanted a faster, cleaner tool for my teambuilding sessions. Instead of giving up because I didn't know how to code, I built this entire project from scratch using AI! It's a proof of concept of how AI can help bring ideas to life.

## ✨ Features
* **Advanced Filtering:** Easily filter Pokémon by **Type**, **Generation**, and **Egg Group** to find exactly what you need for breeding or teambuilding.
* **Instant Search:** No lag, no loading screens. Just type and find.
* **Clean UI:** Built to be readable at a glance during intense matches.

## 🛠️ Tech Stack
Even though I didn't write the code manually, the AI was prompted to use a cutting-edge, high-performance stack:
* **Framework:** React 19 + TanStack Start
* **Data Management:** TanStack Query
* **Styling & UI:** Tailwind CSS v4 + Radix UI + Lucide Icons
* **Charts:** Recharts
